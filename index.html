Co-Dependent Application

This application is co-dependent and strictly requires the companion HokieTutor Chrome Extension to operate. The extension securely scrapes your active Fall 2026 courses from Canvas, synchronizes assignments, and coordinates with the Spring Boot backend AI scheduler.

Listening for HokieTutor Extension...

How to Connect the Extension:

  1. Open chrome://extensions (or edge://extensions) in your browser.
  2. Enable Developer mode using the toggle switch in the upper-right corner.
  3. Click Load unpacked and select the extension folder inside this repository.
  4. Once loaded, click Ping Extension above (or refresh) to unlock the application!
